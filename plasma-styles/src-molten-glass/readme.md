# Theme Overrides
Molten Glass uses a few modifications to maintain legibility under glass constraints.

## Neutral Theme Details
This is a glass theme, and also the first I ever made. It violates nearly every principle I have for legibility in a theme in favor of aesthetics. It is undoubtedly more difficult to read even simple tooltip text and I find myself having to focus harder to read content. Curiously, I now prefer this theme over its original non-molten glass variants.
Background color is currently controlled through the colors file. By overriding the colors file, you can tint panels and dialogs. I suspect that tinting the theme background with a color derived from your wallpaper would alleviate the awkwardness with some colors that I sometimes see in this theme. Dark is probably the true final iteration, but its edge highlights are not vibrant enough for me.
Foreground text color should be defined by opacity, not lightness. Choosing a full opacity color, but mixing it with background color will result in readability issues when shown over a blurred background that is similar in color. Choosing the original color will allow the resulting visible color to mix with the blurred background and generate its own contrast, becoming more readable.
This theme is a dark theme, meaning that the foreground color is white, but the theme can be very bright depending on the background.
